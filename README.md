# Schotland Roadbook 2026

Offline PWA voor de reis van 22 september t/m 7 oktober.

## GitHub Pages publiceren

Deze repository is voorbereid voor GitHub Project Pages onder:

`https://ketaapetaa.github.io/schotland_roadbook/`

Alle app-paden zijn relatief, zodat manifest, service worker en iconen onder `/schotland_roadbook/` blijven werken.

### Eenmalig

1. Zet alle bestanden uit deze map in de root van de repository `schotland_roadbook`.
2. Commit/push naar branch `main`.
3. Open GitHub: **Settings > Pages**.
4. Onder **Build and deployment** kies **Deploy from a branch**.
5. Kies branch **main** en folder **/(root)**, klik **Save**.
6. Wacht tot GitHub Pages de site gepubliceerd heeft.
7. Open `https://ketaapetaa.github.io/schotland_roadbook/`.

### Installeren op iPhone

Open de URL in Safari > Deel > **Zet op beginscherm** > Voeg toe. Open daarna de app en tik op **Maak offline beschikbaar**.

### Installeren op Android

Open de URL in Chrome. Gebruik **App installeren** of Chrome-menu > **App installeren / Toevoegen aan startscherm**. Open daarna de app en tik op **Maak offline beschikbaar**.

### Offline testen

1. Open de geinstalleerde app eenmaal met internet.
2. Tik **Maak offline beschikbaar** en wacht op `Offline gereed`.
3. Zet vliegtuigmodus aan.
4. Sluit de app volledig en open hem opnieuw via het beginscherm.
5. Controleer een paar dagkaarten.
