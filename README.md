# Schotland Roadbook 2026

GitHub Pages PWA voor `KetaaPetaa/schotland_roadbook`.

Upload de **inhoud van deze map** naar de root van `main`. GitHub Pages blijft op `Deploy from branch -> main -> / (root)`.

## Na upload
1. Open https://ketaapetaa.github.io/schotland_roadbook/ en force-refresh.
2. Op ieder toestel eenmaal online openen.
3. Tik **Maak offline beschikbaar** en wacht tot `16/16 kaarten` staat.
4. Installeer via de browser (iPhone: Safari -> Deel -> Zet op beginscherm; Android: Chrome -> App installeren).
5. Test in vliegtuigmodus.

De online kaarten gebruiken OpenFreeMap / OpenStreetMap. Offline kaarten worden door de browser op het toestel als snapshots in IndexedDB bewaard.
